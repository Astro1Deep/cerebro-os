# Cerebro OS 1.5.0-beta.3

[English guide](GUIDE.md) · [Guía en español](GUIA.md)

## English

This release candidate adds portable installation, Composer and Jarvis, local model configuration, Telegram access policies and read-only BeatOS library integration to the public source. Its distribution is built from an allowlist. The personal development stack, local data, biometric voice controls, pre-existing brand assets, live hardware configurations and model weights are outside the portable payload.

The installer supports a new installation directory and the diagnostics distinguish core health from optional Telegram availability. Model requests connect directly to loopback and decline redirects. Jarvis discovers indexed libraries through the BeatOS v2 bridge. The version status is beta. A cross-platform clean dependency installation, live model generation, optional device permissions and physical MIDI/sampler workflows require separate verification on the target environment.

## Español

Esta candidata incorpora al código público el instalador portátil, Composer y Jarvis, configuración de modelos locales, políticas de Telegram e integración de bibliotecas BeatOS en solo lectura. La distribución se construye con una lista explícita de archivos. El stack de desarrollo personal, los datos locales, los controles biométricos de voz, los recursos gráficos anteriores, las configuraciones de equipos reales y los pesos de modelos quedan fuera del paquete portátil.

El instalador utiliza un directorio nuevo y el diagnóstico comprueba la disponibilidad de Telegram como opción independiente. Las peticiones al modelo usan bucle local directo y rechazan redirecciones. Jarvis detecta bibliotecas indexadas mediante el puente BeatOS v2. La versión es beta. La instalación limpia multiplataforma de dependencias, la generación real, los permisos opcionales y las pruebas MIDI y de samplers físicos requieren verificación adicional en cada destino.
